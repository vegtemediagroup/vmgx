# Wikidata item: draft for later

**Do not create this item yet.** Wikidata accepts an item when serious, publicly available references describe it, and creating one about your own project is a conflict of interest. Wait until at least one independent source exists, then ask someone uninvolved to create it, or create it yourself and say openly on the item's talk page that you are connected to VMGX.

Good independent sources, in order of strength:

1. A PRONOM entry (gives the item a "PRONOM file format identifier")
2. The IANA media type registration
3. Coverage by others: an article, a blog post by an archive, use in another project
