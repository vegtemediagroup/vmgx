# VMGX for Visual Studio Code

Support for **VMGX** (`.vmgx`), a lightweight, human-readable data format for structured records, rich metadata and long-term digital preservation.

- **Syntax colors** for keys, metadata keys, text, text blocks, numbers, dates, links and comments
- **Live error checking:** problems are underlined as you type, with the same messages as every other VMGX tool
- **Formatting:** *Format Document* tidies the layout
- **JSON conversion:** *VMGX: Convert to JSON* and *VMGX: Convert to Typed JSON* in the Command Palette
- **Comments:** toggle with the usual shortcut (⌘/ on Mac, Ctrl+/ on Windows)

The extension uses the reference VMGX parser, so it accepts and rejects exactly what the specification says.

Learn more about VMGX at <https://vmgx.vegte.org>. Source code and issues: <https://codeberg.org/vmgx/vmgx>.
